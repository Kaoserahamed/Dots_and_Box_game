# Dots_and_Box_game Authentication Module

## Overview
User authentication system with registration, login, JWT-based session management, and password hashing.

## Files
- `server/auth/AuthService.java` - Authentication logic
- `server/auth/UserModel.java` - User model
- `server/auth/AuthMiddleware.java` - Auth middleware
- `server/auth/AuthController.java` - Auth API endpoints

## Features
- User registration and login
- JWT-based session management
- Password hashing with bcrypt
- Session management
- User profile management

## Tech Stack
- Java/Spring Boot
- PostgreSQL
- JWT
- bcrypt for password hashing
